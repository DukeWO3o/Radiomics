# RMPP Radiomics Analysis Pipeline

This repository contains the analysis code used for the pediatric chest
radiograph radiomics study of treatment-refractory *Mycoplasma pneumoniae*
pneumonia. Inputs, intermediates, model outputs, figures, application assets,
and reporting outputs are all kept inside this pipeline directory.

The code snapshot does not contain patient data, images, masks, trained model
weights, or generated analysis results. Those files must be placed in the
documented input locations.

## Required Input Files

Place source DICOM files and reviewed masks in the group-specific subfolders
under `00_InputData/Images`. The expected clinical metadata files are:

| File | Purpose |
|---|---|
| `00_InputData/Clinical/names.xlsx` | Name lookup used to rename source folders |
| `00_InputData/Clinical/rmpp_names.xlsx` | RMPP case list used during source grouping |
| `00_InputData/Clinical/sampling_cohort.xlsx` | Full cohort used to sample 50 reproducibility cases |
| `00_InputData/Clinical/clinical_931.xlsx` | Full clinical and radiomics workbook before ICC filtering |
| `00_InputData/Clinical/clinical_931.sav` | Baseline-analysis dataset |
| `00_InputData/Modelling/model_data_931.xlsx` | Final 931-case modelling input, generated by `H-5` or supplied directly |
| `00_InputData/PixelSpacing/model_data_497.xlsx` | Final 497-case PixelSpacing modelling input, generated by `H.pyradiomics_ImagerSpacing.py` or supplied directly |
| `00_InputData/Demo/*.dcm` | De-identified demonstration DICOM files |

The second-reader masks are stored under:

```text
04_Modelling/Reproducibility/ROI_review_50cases/
|-- RMPP/02_Mask_R2/
`-- nonRMPP/02_Mask_R2/
```

Second-reader radiomics tables are expected as:

```text
04_Modelling/Reproducibility/ROI_review_50cases/RMPP-2.csv
04_Modelling/Reproducibility/ROI_review_50cases/nonRMPP-2.csv
```

## Environment

The main modelling workflow used Python 3.7 and scikit-learn 1.0.2.
Required packages include PyRadiomics, pandas, NumPy, SciPy, statsmodels,
scikit-learn, XGBoost, LightGBM, SHAP, pymrmr, joblib, openpyxl, pillow, and
matplotlib. The application environment is documented in
`06_RMPP_Prediction_App_CV/environment.yml`. U-Net training requires a PyTorch
environment with GPU support when available.

## Preprocessing

Run from the `Pipeline` directory:

```bash
python 01_PreProcess/A.dat转txt.py
python 01_PreProcess/B.利用2023姓名表重命名.py
python 01_PreProcess/C.重命名DCM或JPG.py
python 01_PreProcess/D.利用2023RMPP筛选RMPP.py
python 01_PreProcess/E.DCM图像标准化.py
python 01_PreProcess/F.binarization.py
python 01_PreProcess/G.名字转换为拼音.py
python 01_PreProcess/H.pyradiomics.py --group RMPP
python 01_PreProcess/H.pyradiomics.py --group nonRMPP
```

`E.DCM图像标准化.py` creates standardized PNG images from each group's
`00_DCM` directory. `F.binarization.py` creates `03_Binarized` masks from
`02_Mask`. `G.名字转换为拼音.py` aligns image and mask filenames.
`H.pyradiomics.py` writes feature tables to `04_Modelling/Features`.

The 497-case PixelSpacing branch uses:

```bash
python 01_PreProcess/E.DCM图像标准化_ImagerSpacing.py --spacing-source pixel
python 01_PreProcess/H.pyradiomics_ImagerSpacing.py --audit-dir 04_Modelling/PixelSpacing/Preprocessing --branch-slug pixel_spacing_497 --r2-root 04_Modelling/PixelSpacing/Preprocessing/R2_transformed_masks
```

## Reproducibility Analysis

```bash
python 02_OriginalData/H-2.sample_for_ICC.py
python 02_OriginalData/H-3.copy_sampled_files.py
python 02_OriginalData/H-4.calculate_dice.py
python 02_OriginalData/H-5.calculate_ICC.py
```

`H-2.sample_for_ICC.py` selects 50 stratified cases and creates the mapping
table. `H-3.copy_sampled_files.py` prepares the working folder for the second
reader. After the second-reader masks and feature tables are added,
`H-4.calculate_dice.py` computes inter-rater Dice and
`H-5.calculate_ICC.py` computes ICC and writes the final
`00_InputData/Modelling/model_data_931.xlsx`.

`audit_dicom_spacing.py` audits DICOM spacing metadata and writes records to
`04_Modelling/Preprocessing`.

## Main Strict-CV Models

```bash
python 03_FeatureSelection_Step/I.refactored_pipeline_strict_cv.py --modality clinical
python 03_FeatureSelection_Step/I.refactored_pipeline_strict_cv.py --modality radiomics
python 03_FeatureSelection_Step/I.refactored_pipeline_strict_cv.py --modality combined
```

This script performs subject-level splitting, fold-internal imputation,
variance filtering, Z-score standardization, Mann-Whitney FDR screening,
mRMR selection, model tuning, internal validation, calibration, DCA, SHAP, and
DeLong analysis. Results are written to the corresponding directories under
`04_Modelling`.

```bash
python 03_FeatureSelection_Step/I-5.repeated_5x5_cv_strict.py --modality combined
python 03_FeatureSelection_Step/J.correlation_age_ROI.py
python 03_FeatureSelection_Step/K.build_table3_same_svm_strict_cv.py --write-or6
```

`I-5.repeated_5x5_cv_strict.py` performs fixed-parameter repeated CV.
`J.correlation_age_ROI.py` performs Spearman correlation with age and ROI
pixels. `K.build_table3_same_svm_strict_cv.py` creates Table 3 and Online
Resource 6 from the three locked SVM outputs.

`L.sync_strict_cv_downstream.py` synchronizes the combined-model outputs with
Online Resources 4, 5, and 8 and the application model bundle. The required
supplementary templates must be present in `04_Modelling/Supplementary`.

## Threshold and Calibration Analysis

```bash
python 03_FeatureSelection_Step/S.Threshold_Calibration/build_threshold_calibration_outputs.py
```

This script uses the locked SVM validation predictions to calculate threshold
metrics, bootstrap confidence intervals, calibration statistics, DCA, and
Fig. 6. Outputs are written to `04_Modelling/ThresholdCalibration`,
`04_Modelling/Supplementary`, and `Figures`.

## 497-Case PixelSpacing Sensitivity Analysis

```bash
python 03_FeatureSelection_Step/N.retune_imager_spacing_branches.py --branch pixel_both
python 03_FeatureSelection_Step/I.refactored_pipeline_strict_cv_imager_no_combat.py --modality combined --input-file 00_InputData/PixelSpacing/model_data_497.xlsx --output-root 04_Modelling/PixelSpacing/NoCombat --parameter-file 04_Modelling/PixelSpacing/NoCombat/14_Tuning_Best_Parameters.json
python 03_FeatureSelection_Step/I.refactored_pipeline_strict_cv_combat.py --modality combined --input-file 00_InputData/PixelSpacing/model_data_497.xlsx --output-root 04_Modelling/PixelSpacing/Combat --parameter-file 04_Modelling/PixelSpacing/Combat/14_Tuning_Best_Parameters.json
python 03_FeatureSelection_Step/O.verify_imager_spacing_tuning.py
python 03_FeatureSelection_Step/R.report_pixel_spacing_497_results.py
python 03_FeatureSelection_Step/S.Threshold_Calibration/build_online_resource_11_pixel_spacing.py
```

These scripts evaluate the No ComBat and fold-internal ComBat branches using
patient-plane `PixelSpacing`. The separate 931-case `ImagerPixelSpacing`
experiment is not part of the manuscript and is not included here.

## Baseline Analysis

```bash
python 05_Baseline/baseline_v3_final.py
```

This script reads `00_InputData/Clinical/clinical_931.sav` and writes Table 1
to `05_Baseline/Output`.

## U-Net and Application

```bash
python 06_RMPP_Prediction_App_CV/train_unet_independent_test.py
python 06_RMPP_Prediction_App_CV/export_unet_test_results.py
python -m streamlit run 06_RMPP_Prediction_App_CV/app.py
```

`train_unet_independent_test.py` trains the segmentation network with
651/140/140 training, validation, and locked test partitions.
`export_unet_test_results.py` builds the internal U-Net result workbook.
`app.py` runs the Streamlit research prototype using files from
`06_RMPP_Prediction_App_CV/models`.

```bash
python 06_RMPP_Prediction_App_CV/benchmark_end_to_end.py
python 06_RMPP_Prediction_App_CV/pipeline_consistency/compare_research_deployment_pipeline.py
python 06_RMPP_Prediction_App_CV/pipeline_consistency/unet_results.py
python 06_RMPP_Prediction_App_CV/pipeline_consistency/pipeline_consistency.py
python 06_RMPP_Prediction_App_CV/pipeline_consistency/end_to_end_timing.py
```

These scripts measure the deployed computation path and compare research and
deployment segmentation/extraction pipelines. The final U-Net and consistency
content is written to
`04_Modelling/Supplementary/Online_Resource_9_U-Net_and_pipeline_validation.xlsx`.

## Scope

The pipeline excludes historical LightGBM models, early LASSO variants,
unpublished `ImagerPixelSpacing` experiments, manuscript-editing tools,
patient data, generated results, and trained model binaries.
